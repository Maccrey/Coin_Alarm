# Coin Alarm

암호화폐 시세 모니터링 및 알림 앱

## 기능 소개

### 기본 기능

- 암호화폐 실시간 시세 조회
- 가격 알림 설정 및 관리
- 코인 관련 뉴스 피드

### 추가된 기능 (2024-06-12)

- 테마 설정 (라이트/다크/시스템)
- 언어 설정 (한국어/영어)
- 로그인 정보 저장 기능
- 설정 초기화 기능

### 추가된 기능 (2024-06-13)

- API 키 설정 기능 (Upbit, Binance)
- 개인정보 처리방침 (한국어/영어)
- 이용약관 (한국어/영어)
- UI 개선: 확장 가능한 설정 패널
- 문서별 언어 전환 기능 (개인정보 처리방침, 이용약관)

### 추가된 기능 (2024-06-14)

- 코인 차트 화면 구현 (캔들스틱/라인 차트 지원)
- 차트 기간 선택 기능 (1일, 1주일, 1개월, 3개월, 1년, 전체)
- 차트 확대/축소 기능
- 홈화면 코인 목록에서 선택한 코인으로 차트 화면 전환 기능
- 앱 런처 아이콘 설정

## 개발 환경

- Flutter 3.19.0
- Dart 3.3.0
- Supabase

## 구현 기술

- MVVM 패턴
- Provider 상태관리
- SharedPreferences를 통한 로컬 데이터 저장
- Supabase 연동 (준비 중)
- flutter_launcher_icons 패키지를 활용한 앱 아이콘 설정

## 보안 특징

- API 키는 로컬에만 저장되며 서버로 전송되지 않음
- 개인정보 보호를 위한 안전한 데이터 처리
