# Coin Alarm

암호화폐 가격 알림 및 모니터링 앱입니다.

## 주요 기능

### 대시보드

- 실시간 코인 가격 모니터링
- 코인별 가격 변동 추이 확인
- API를 통해 지원하는 모든 코인 선택 가능
- 업비트 거래소 지원

### 설정

- 테마 설정 (라이트/다크 모드)
- 새로고침 간격 설정 (1초~5분까지 세분화)
- 언어 설정 (한국어/영어)
- API 키 관리 (업비트/바이낸스)
- 생체인증 및 푸시알림 설정

### 차트

- 코인별 차트 데이터 확인
- 기간별 데이터 확인 (1일/1주일/1개월/3개월/1년/전체)
- 마지막 업데이트 시간 표시
- 실시간 데이터 업데이트

### 알림

- 가격 변동 알림 설정
- 알림 이력 관리

### 기타

- 개인정보 처리방침 및 이용약관 제공 (한국어/영어)
- 로그인 정보 저장 기능

## 사용 방법

### 데이터 새로고침 간격 설정

1. 설정 화면으로 이동합니다.
2. '데이터 새로고침 간격' 항목을 선택합니다.
3. 원하는 간격(1초, 2초, 5초, 10초, 15초, 30초, 1분, 2분, 5분)을 선택합니다.
4. 설정한 간격에 따라 대시보드와 차트 화면의 데이터가 자동으로 업데이트됩니다.
5. 간격이 짧을수록 실시간에 가깝지만 배터리 소모가 증가합니다.

### 코인 선택

1. 대시보드 화면에서 '코인 선택' 버튼을 누릅니다.
2. 지원하는 모든 코인 목록이 표시됩니다.
3. 검색창을 통해 원하는 코인을 빠르게 찾을 수 있습니다.
4. 원하는 코인을 선택하고 '확인' 버튼을 누릅니다.
5. 선택한 코인만 대시보드에 표시됩니다.

## API 키 설정

1. 설정 화면으로 이동합니다.
2. 'API 키 설정' 항목을 선택합니다.
3. 업비트 또는 바이낸스 API 키를 설정합니다.
4. API 키는 앱 내부 저장소에만 저장되며 외부로 전송되지 않습니다.
